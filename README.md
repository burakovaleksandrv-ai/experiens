# ExperienS — статический сайт

137 страниц: главная, справочник со 126 навыками, 7 страниц сфер, трекер недели, «Как это работает».
Сервер не нужен — только раздача файлов.

## Что внутри

```
index.html              главная
spravochnik/            список 126 навыков + поиск и фильтр
spravochnik/1.4.1.html  страница навыка (126 штук, id = сфера.подсфера.номер)
sfery/1.html            страница сферы (7 штук)
treker/                 трекер недели, состояние в localStorage браузера
mehanika/               правила простым языком
assets/style.css        единственная таблица стилей
assets/spravochnik.js   поиск и фильтр справочника
```

## Как выложить

**GitHub Pages** — создать репозиторий, положить туда содержимое папки, включить Pages в настройках
(Settings → Pages → Deploy from a branch → main / root). Бесплатно, свой домен подключается там же.

**Netlify или Cloudflare Pages** — перетащить папку в браузерное окно загрузки. Бесплатно, HTTPS сразу.

**Обычный хостинг** — залить папку в корень сайта по FTP.

Все ссылки относительные, поэтому сайт одинаково работает и в корне домена, и в подпапке,
и просто открытый с диска двойным кликом по `index.html`.

## Чего сайт не делает

Трекер хранит прогресс в localStorage — это отдельная копия в каждом браузере. Разные люди не видят
данные друг друга, но и вы не видите их: аккаунтов и общей базы здесь нет. Для многопользовательской
версии нужен бэкенд — см. документ «Механика ExperienS» в проекте.

## Как обновлять контент

Страницы навыков и справочника собираются скриптом из книги данных и справочника v2.1.
Руками их править не нужно: изменение начинается со справочника, дальше пересборка.
